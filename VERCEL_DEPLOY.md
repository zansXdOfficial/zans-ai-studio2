# Deploy Vercel
1. Upload seluruh isi folder ini ke GitHub.
2. Vercel → Add New → Project → Import repository.
3. Framework: Other.
4. Environment Variables → `OPENAI_API_KEY` = API key OpenAI.
5. Deploy.
6. Buka URL `*.vercel.app`.
Jangan upload `.env`. Watermark `ZANE OFC` dipasang server-side. Font stack mendekati Matcha Mint; untuk font resmi, tambahkan file berlisensi dan ajuste o SVG.
